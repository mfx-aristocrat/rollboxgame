# Asset register

Initial policy: source-generated geometry, UI, colors, lighting and effects only. No imported models, textures, music, fonts or audio assets are included. Roblox built-in UI font and engine primitives are used through supported APIs. No third-party asset rights are assumed.

Record origin URL, author, license/permission, asset ID and purpose here before adding externally authored assets. Tool binaries are development dependencies pinned in tools.lock.json, not shipped game assets.
